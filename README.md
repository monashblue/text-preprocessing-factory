# The Text Preprocessing Factory

An interactive web-based educational game designed to help users understand Information Retrieval Systems. Players act as text processing operators tasked with cleaning raw sentences so they are ready for search engine indexing.

## Core Technologies

* **HTML5:** Interface structure and layout markup
* **CSS3:** Visual design, styling, and responsive layout
* **Vanilla JavaScript (ES6+):** Game mechanics, scoring logic, and state management
* **Supabase:** Backend database for real-time leaderboard management

## How to Play

1. Click the **Start Game** button.
2. Observe the sentence or word appearing on the conveyor belt.
3. Click **Tokenizing** to split sentences into individual words.
4. Click **Stopword Removal** to filter out common conjunctions and noise words.
5. Click **Stemming** to reduce inflected words to their root forms.
6. Score as many points as possible before running out of lives!
